PTS STUDIO 3.0 — โปรแกรมแก้ไขตารางแมป ECU ที่สร้างขึ้นใหม่

โปรแกรมนี้ทำงานด้วยตนเอง ไม่ต้องติดตั้ง TunerPro หรือ WinOLS ไม่มีหน้ากลางเปิดโปรแกรมภายนอก
ซอร์สชุดนี้พัฒนาขึ้นใหม่สำหรับ PTS ไม่มีการนำซอร์สภายในของสองโปรแกรมนั้นมาใช้

เพิ่มในรุ่น 3.0
- นำเข้า XDF XML: ตาราง ค่าคงที่ BASEOFFSET DEFAULTS ลำดับไบต์ และ signed
- รองรับเฉพาะ XDF ที่ major/minor stride เป็น 0 โดยข้ามรายการที่ไม่รองรับพร้อมรายงาน
- แกน LABEL แบบตัวเลข และแกนตำแหน่ง BIN โดยตรง แกนอ้างอิงที่อ่านไม่ได้ใช้หมายเลขช่องพร้อมรายงาน
- integer 8/16/32 และ IEEE754 float32 พร้อมการจัดเก็บ row-major / column-major
- สูตร X และ + - * / ** แบบจำกัด ไม่รันโค้ด Python และไม่มีการเรียกฟังก์ชัน
- สูตรเชิงเส้นแปลงกลับอัตโนมัติ สูตรไม่เชิงเส้นไม่มีสูตรกลับเปิดอ่านอย่างเดียว
- กำหนดสูตรกลับเองได้ มีการตรวจผลก่อนเขียนและทดสอบ roundtrip กับค่าปัจจุบัน
- แก้ไบต์ HEX โดยตรง ค้นหา/ไปยังตำแหน่ง และรายงาน diff CSV
- ส่งออก/นำเข้าแพตช์ข้อมูล PTS ตรวจ SHA-256 ต้นทางและปลายทางก่อนเขียน
- เปิดโครงการ v2 เดิมได้ และบันทึกใหม่เป็น .pts3 เพื่อป้องกันเวอร์ชันเก่าอ่านสูตร/float ผิด
- ค้นหารายการแมปตามชื่อหรือหมวดหมู่ที่นำเข้าจาก XDF

ทดลอง XDF
เปิด demo.bin แล้วเลือก แมป → นำเข้า XDF และเลือก demo.xdf
ตรวจรายงานการนำเข้าและค่าตาราง ตัวอย่างนี้สร้างขึ้นสำหรับทดสอบเท่านั้น

การเริ่มใช้งานบน Windows
1. แตก ZIP ทั้งหมดไปโฟลเดอร์เดียวกัน
2. หากมี Python 3 พร้อม Tcl/Tk และ Python Launcher แล้ว เปิด START.bat
3. เลือก ไฟล์ → เปิดตัวอย่างฝึกใช้งาน เพื่อทดลองตารางและกราฟทันที
4. ถ้าต้องการไฟล์ EXE เปิด BUILD_EXE.bat บน Windows
   ครั้งแรกต้องใช้อินเทอร์เน็ตเพื่อติดตั้ง PyInstaller
   เมื่อสำเร็จจะได้ dist\PTS_Studio_3.exe และมี build_log.txt
   EXE ที่สร้างสำเร็จจะใช้ได้โดยไม่ต้องติดตั้ง Python บนเครื่องปลายทางสถาปัตยกรรมเดียวกัน
   ชุดที่ส่งมานี้ยังเป็นซอร์สและสคริปต์สร้าง EXE ไม่มี EXE ที่คอมไพล์แล้ว

ฟังก์ชันที่พัฒนาแล้ว
- พื้นที่ทำงานขยายเต็มหน้าต่าง เปิดแบบขยายสูงสุดเมื่อระบบรองรับ
- F10 ตารางเต็มพื้นที่ ซ่อนส่วนหัวและรายการแมป / F11 เต็มหน้าจอ / Esc ออก
- ตารางสีไล่ตามค่า เลือกหลายช่องด้วยการลากหรือ Shift+คลิก
- แก้ค่าเดี่ยวหรือหลายช่อง บวก/ลบ คูณ เปอร์เซ็นต์ ไล่ค่าระหว่างจุด ปรับผิว
- คัดลอกและวางค่าตารางแบบแท็บ/จุลภาค พร้อมปฏิเสธชุดข้อมูลที่เกินขอบเขต
- ตัวแก้ไข BIN 8/16/32 บิต little/big endian และ signed/unsigned
- สูตรเชิงเส้น ค่าแสดง = ค่าดิบ × ตัวคูณ + ค่าชดเชย
- ระบุหน่วย และแกนคงที่สำหรับแถว/คอลัมน์ได้
- ค่าที่บันทึกกลับถูกปัดเป็นจำนวนเต็มตามขนาดบิต ไม่มีการ clamp ค่าล้นช่วง
- กราฟ 2D แยกเส้นตามแถว กราฟพื้นผิว 3D ลากหมุนและล้อเมาส์ซูม
- 3D แบบหน้าต่างแยกที่เปิดพร้อมตารางได้ ปิดด้วย Esc หรือ X
- กราฟ 3D ของตารางใหญ่ลดความละเอียดการวาดเหลือประมาณ 32×32 ช่อง
- รายการแมป ค้นหาชื่อ เรียงชื่อ/ขนาด สร้าง/แก้นิยาม และนำเข้า/ส่งออก JSON
- เปรียบเทียบไฟล์ขนาดเท่ากัน โดยแสดงมุมสีทองในช่องที่ต่างจากไฟล์อ้างอิง
- ค้นหา HEX และดูไบต์พร้อม ASCII สูงสุด 8 KB จากตำแหน่งปัจจุบัน
- ค้นหาบล็อกข้อมูลต่อเนื่องที่อาจเป็นแมป: ตรวจบล็อก 16×16 ใน 2 MB แรก
  ผลนี้เป็นเพียงบล็อกรอตรวจ ไม่ใช่ระบบระบุหน้าที่แมปหรือรหัส ECU
- ย้อนกลับ/ทำซ้ำเป็นชุด และคืนค่าช่องที่เลือกจากต้นฉบับ
- โครงการ .pts3 เก็บต้นฉบับ ข้อมูลที่แก้ไข นิยามแมป และเวอร์ชันสูงสุด 5 ชุด
- ส่งออก BIN ชื่อใหม่ ส่งออกตาราง CSV พร้อมแกน
- ธีม ดำ–แดง / กรมท่า–ฟ้า / เทา–ทอง พร้อมจดจำธีม
- เมนูและคำอธิบายของ PTS เป็นภาษาไทย ส่วนกล่องเลือกไฟล์ระบบใช้ภาษาของ Windows

หลักการใช้งาน
เปิด BIN แล้วสร้างนิยามแมปให้ตรงกับตำแหน่งและรูปแบบข้อมูลจริง
ไฟล์ตัวอย่างเป็นข้อมูลสังเคราะห์สำหรับเรียนรู้ UI เท่านั้น ไม่ใช่ไฟล์รถจริง
แกนคงที่ที่ป้อนด้วยมือไม่มีผลต่อไบต์ BIN เป็นเพียงข้อมูลในโครงการ
แกนที่อ่านจาก BIN เมื่อนำเข้า XDF เป็นสำเนาค่าขณะนำเข้า ไม่อัปเดตอัตโนมัติหากแก้ไบต์แกนภายหลัง
คำสั่งไล่ค่าใช้ระยะห่างตามหมายเลขช่อง ไม่ใช่ระยะห่างทางกายภาพของแกน
คำสั่งปรับผิวใช้ค่าเฉลี่ยเพื่อนบ้านสี่ทิศผสมค่าปัจจุบันในหนึ่งรอบ
ส่งออก CSV มีแกนด้วย แต่คำสั่งวางในตารางรับเฉพาะตัวเลขค่าตาราง ไม่รวมแกน
ซอร์สไม่พึ่งแพ็กเกจ Python ภายนอกขณะใช้งาน มีเพียง PyInstaller ที่ใช้ตอนสร้าง EXE

ขอบเขตที่ยังไม่รองรับ
- XDF ที่ใช้ stride ไม่เป็นศูนย์ สูตรต่อช่อง/แถว/คอลัมน์ ตัวแปรสูตรจากภายนอก
- XDF bit flags / patches, linked axes ที่อ่านไม่ได้, IEEE754 64 บิต
- ADX / A2L / DAMOS / โครงการ OLS
- ปลั๊กอินและ checksum เฉพาะ ECU ของผู้ผลิต
- สูตรที่เรียกฟังก์ชัน เช่น IF หรืออ้างอิงตารางอื่น และแมปแบบกระโดดข้ามไบต์
- การเชื่อมต่อ Openport/K-Line อ่าน/เขียน ECU บันทึกสด และจำลอง ECU
- ไม่รับรองความเทียบเท่าฟังก์ชันทั้งหมดของ TunerPro และ WinOLS
SHA-256 และ CRC32 เป็นแฮชไฟล์ทั่วไป ไม่ใช่การแก้ checksum ECU
การแก้ไขและส่งออก BIN ไม่ใช่การยืนยันว่าไฟล์พร้อมแฟลช
รองรับ BIN ไม่เกิน 32 MB และตารางสูงสุด 128×128 ช่อง

ผลตรวจในสภาพแวดล้อมที่สร้าง
ตรวจไวยากรณ์ซอร์สแล้ว ทดสอบแก้ไขไบต์ การแปลงค่า ย้อนกลับ ขอบเขต ค่าล้นช่วง
การไล่ค่า ปรับผิว และการบันทึก/เปิดโครงการ ผ่าน 28 กรณี
ยังไม่มีการตรวจ GUI บน Windows หรือการทดสอบ EXE ที่คอมไพล์แล้ว

core.py       แกนจัดการข้อมูลไบนารีและประวัติย้อนกลับ

patches.py     แพตช์ข้อมูลพร้อมตรวจ SHA-256
