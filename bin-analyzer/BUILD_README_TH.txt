ชุดเตรียมสร้าง PTS BIN Analyzer v3 เป็น Windows EXE
ยังไม่ใช่ไฟล์ EXE ที่สร้างเสร็จ

1. แตก ZIP ทั้งหมดบน Windows 64 บิต
2. ต้องมี Python 3 x64 พร้อม Tcl/Tk และอินเทอร์เน็ตสำหรับครั้งที่ build
3. เปิด BUILD_WINDOWS_EXE.bat
4. เมื่อสำเร็จ จะได้ dist\PTS_BIN_Analyzer_v3.exe
5. ไฟล์ EXE ที่ได้รวม Python, Capstone, ตาราง ECU และ ROM 61 ไฟล์ไว้ในตัว
   เครื่องที่นำ EXE ไปเปิดไม่ต้องติดตั้ง Python

สคริปต์ build จะติดตั้งเครื่องมือใน build-env ข้างซอร์ส
ตรวจการเปิด GUI/การอ่านตารางและ BIN จำลองทั้งก่อนและหลัง build
ไม่เชื่อมต่อหรือส่งคำสั่ง ECU ในขั้น build/test และไม่อัปโหลดข้อมูลไป GitHub
การติดตั้งไดรเวอร์และ native libftdi/libusb สำหรับ FTDI ยังต้องจัดการแยก
ไม่เพิ่มการรองรับแฟลชรุ่นอื่น การอ่าน–เขียน MEN-E21 ยังเป็นโค้ดทดลอง
ซอร์สทดสอบการอ่านไฟล์แล้ว แต่ยังไม่ได้ build/test EXE บน Windows ในรอบนี้
