PTS BIN Analyzer 3.0

การเปิด
ติดตั้ง Python 3 พร้อม Tcl/Tk แตก ZIP แล้วเปิด START_WINDOWS.bat
โหมดตรวจไฟล์ไม่ต้องติดตั้งไลบรารีเพิ่ม
เป็นซอร์ส Python ไม่ใช่ Windows EXE

สิ่งที่เพิ่ม
1. คลัง ROM 61 ไฟล์และข้อมูล ECU 83 รายการจากผู้ใช้
2. เปิด BIN แล้วกดวิเคราะห์ BIN เพื่ออ่าน SHA-256, ขนาด, ข้อความ ASCII,
   ข้อความเบอร์กล่อง, ตำแหน่งไบต์ตรง Software ID และลักษณะข้อมูลแต่ละช่วง
3. เปรียบเทียบกับไบต์ตัวอย่าง Init/ID/Programming/Reset ของผู้ใช้
   การพบไบต์ตรงกันไม่พิสูจน์ว่าเป็นคำสั่งที่ CPU เรียกใช้
4. ส่งออกรายงาน TXT/JSON ผลวิเคราะห์ทั้งหมดเป็นออฟไลน์ ไม่ส่งข้อมูลเข้ากล่อง
5. Disassembly แบบเลือก CPU และ address เอง ต้องติดตั้ง Capstone เพิ่มด้วย
   python -m pip install capstone
   แสดงเฉพาะ CPU ที่ Capstone รุ่นที่ติดตั้งรองรับตามรายการในโปรแกรม
   ไม่ระบุ CPU ให้อัตโนมัติ และไม่ใช้ ARM แทน Renesas โดยเดา
   Load base คือ address ที่ตรงกับ byte แรกของไฟล์ สำหรับ mapping แบบต่อเนื่อง
   ถ้าไฟล์มีหลาย segment หรือข้อมูลไม่ใช่ machine code ผลอาจไม่ถูกต้อง
   ไม่ใช่ decompiler และไม่สามารถถอดสูตร Seed/Key ให้โดยอัตโนมัติ

ความหมายของผล
- ขนาดตรง: เพียงขนาดไฟล์เท่ากัน ไม่ยืนยันรุ่นหรือ compatibility
- ชื่อไฟล์ตรง: ข้อมูลอ้างอิงจากชื่อ ซึ่งเปลี่ยนได้
- ID/Part number พบใน BIN: เป็นตำแหน่งที่พบข้อมูล ไม่ใช่การอ่านรหัสจากกล่องจริง
- Entropy สูง: ไม่ได้ยืนยันการเข้ารหัสหรือบีบอัด
- รายงานไม่ใช่สคริปต์แฟลช และไม่มีการเปิดการแฟลชรุ่นอื่นจากผลวิเคราะห์

ส่วนอ่าน–เขียนฮาร์ดแวร์
คงเฉพาะโค้ด MEN-E21 รุ่นทดลองเดิม ไม่มีการเพิ่มการรองรับ ECU จากการเดา BIN
ดู FLASH_EXPERIMENT_README_TH.txt ซึ่งอธิบาย FTDI, ไดรเวอร์, การสำรอง และข้อจำกัด
ยังไม่ผ่านการทดสอบกับ ECU จริง/Windows GUI

ตัวอย่าง CLI
python bin_analysis.py "ไฟล์.bin" --json "report.json" --text "report.txt"
ไฟล์รายงาน CLI ต้องเป็นชื่อใหม่ และต้องไม่ใช่ BIN ต้นฉบับ
